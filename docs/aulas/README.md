# Aulas do Eruption Engine

Aulas curtas para fazer um jogo do começo ao fim no editor, sem escrever código no
começo: o mapa sai do gerador, os objetos e personagens vêm arrastados do painel
Projeto e o que acontece no jogo é montado na **folha de regras** (frases como
"Quando o jogador entrar na área porta → Mostrar a mensagem ...").

Para a interface em português: **Janela > Idioma: Português**.

| Aula | O que se faz |
|---|---|
| [1. Primeiro mapa](01-primeiro-mapa.md) | Gerar um mapa com morros, rio, estrada e água; andar nele |
| [2. Objetos e personagens](02-objetos-e-personagens.md) | Pôr modelos, prefabs e personagens; mover, girar, deixar sólido |
| [3. A primeira regra](03-primeira-regra.md) | Área de gatilho, mensagem na tela e uma porta que abre |
| [4. Som e música](04-som-e-musica.md) | Música de fundo, som ao entrar numa área |
| [5. Personagens que andam e falam](05-personagens-que-andam-e-falam.md) | Caminho desviando de obstáculos, balão de fala, animações |
| [6. Salvar e trocar de mapa](06-salvar-e-trocar-de-mapa.md) | Jogo salvo, portas para outro mapa |
| [7. Mundo contínuo](07-mundo-continuo.md) | Mapas emendados, sem tela de carregamento |
| [8. Das regras para o código](08-das-regras-para-o-codigo.md) | Ver o código das regras, scripts Luau, depurador no VS Code |
| [9. Exportar o jogo](09-exportar.md) | Uma pasta que roda sozinha, sem o editor |
| [10. Código em C++](10-codigo-em-cpp.md) | Módulo C++ que recompila e recarrega com o jogo rodando |

Atalhos que valem para todas as aulas:

- **Ctrl+Shift+P** procura qualquer comando pelo nome.
- **F5** joga dentro da cena; parar devolve a cena como estava.
- **Ctrl+S** salva a cena (o jogo lê o mesmo arquivo).
- **Ctrl+Z / Ctrl+Y** desfaz e refaz.
